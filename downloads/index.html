Installing this test build

Android 8 or newer is required. Open the downloaded APK and allow installation from your browser or file manager when Android asks.

This is a beta build, signed with the same development key as the first APK. It can update that build in place; export a backup first. This update adds fullscreen/system-bar handling, theme and font choices, notification history, live storage metrics, and dated folder backups. Export a backup before replacing an existing installation or switching signing keys. Pixel 7a/GrapheneOS testing, particularly Doze and locked-screen reminders, is still pending.

Enable notifications in VIKI Settings. Precise reminders require Android's separate exact-alarm access. Force-stopping the app prevents reminders until you open it again.

Local data remains on your device. Export backups before clearing app data or uninstalling.
